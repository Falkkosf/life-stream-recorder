# 🔴 Multi-Platform Live Recorder

Десктопное GUI-приложение (Python + CustomTkinter) для записи прямых эфиров и VOD'ов сразу с нескольких платформ одновременно, с автоматической нарезкой на файлы фиксированной длины, без разрывов потока и без блокировки файлов во время записи.

Поддерживаемые платформы: **Twitch, YouTube, Kick, Rumble, Trovo, W.tv, Wasd.tv**, а также произвольный URL — если его понимает `yt-dlp`.

---

## Зачем это нужно

Если вы монтажёр, клипмейкер или просто хотите архивировать эфиры любимых стримеров, стандартные способы записи (OBS, "просто скачать VOD целиком") имеют проблемы:

- **VOD ещё идущего стрима нельзя скачать одним куском** — Twitch отдаёт растущий плейлист с коротким скользящим буфером (60–90 сек), и обычная попытка скачать "с начала и до упора" виснет или обрывается.
- **Файл, который ещё пишется, нельзя открыть в монтажке** — он залочен процессом записи.
- **Остановка записи по кнопке "Стоп" часто не убивает процесс до конца** — `yt-dlp`/`streamlink` порождают дочерний `ffmpeg`, который продолжает висеть в фоне.

Эта программа решает все три проблемы:

- Пишет поток через связку `streamlink`/`yt-dlp → pipe → ffmpeg -f segment -c copy`, поэтому **входящий поток режется на файлы по GOP-границам без остановки закачки и без перекодирования** — как только очередной кусок закрыт, он сразу готов к монтажу.
- Есть отдельный режим **VOD во время эфира**: программа умеет докачивать ещё растущий архив Twitch маленькими кусками (обходя проблему скользящего DVR-буфера) и склеивать их в файлы нужного размера — можно начинать монтаж, пока стример ещё в эфире.
- Корректно "убивает" всё дерево дочерних процессов при остановке (`taskkill /T` на Windows, `killpg` на Linux/macOS) — ничего не остаётся висеть в фоне.
- Позволяет вести **несколько записей параллельно** — по одной карточке-сессии на каждого стримера/канал, с независимым логом и статусом.

---

## Возможности

- 🎛 Несколько параллельных сессий записи (по кнопке "➕ Добавить стримера")
- 🌐 8 платформ + произвольный URL, понятный `yt-dlp`
- 🔴 Режим **"Поток"** — запись идущего эфира с нарезкой на сегменты заданной длины
- 📼 Режим **"VOD"** — скачивание архива:
  - если VOD уже завершён — обычная закачка целиком с нарезкой на сегменты;
  - если стрим ещё идёт — автопоиск последнего VOD канала по нику, докачка "хвоста" мелкими порциями и склейка их в финальные файлы (без перекодирования, `ffmpeg -f concat -c copy`);
  - защита от бесконечной повторной перекачки одного и того же VOD после окончания эфира.
- ⚙️ Настройки на выбор: папка сохранения, размер сегмента (1–360 минут), качество для Twitch (best / 1080p60 / … / worst)
- 💾 Сохранение всех сессий и настроек между запусками (`live_recorder_config.json`)
- 📋 Лог каждой сессии с копированием в буфер и очисткой
- 🪟 Тёмный интерфейс на CustomTkinter, без консольных окон дочерних процессов на Windows

## Требования

- **Python 3.9+**
- **ffmpeg** и **ffprobe** — должны быть доступны в `PATH`
- Python-пакеты:
  - `customtkinter`
  - `yt-dlp`
  - `streamlink`

### Установка

1. Установите Python 3.9 или новее ([python.org](https://www.python.org/downloads/)).

2. Установите ffmpeg и добавьте его в `PATH`:
   - **Windows**: скачайте сборку с [gyan.dev](https://www.gyan.dev/ffmpeg/builds/) или [ffmpeg.org](https://ffmpeg.org/download.html), распакуйте и добавьте папку `bin` в переменную окружения `PATH`.
   - **macOS**: `brew install ffmpeg`
   - **Linux**: `sudo apt install ffmpeg` (Debian/Ubuntu) или аналог для вашего дистрибутива.

   Проверьте, что всё установлено:
   ```bash
   ffmpeg -version
   ffprobe -version
   ```

3. Установите Python-зависимости:
   ```bash
   pip install customtkinter yt-dlp streamlink
   ```

4. Скачайте `TwitchBIG.py` (или склонируйте репозиторий) и запустите:
   ```bash
   python TwitchBIG.py
   ```

> Приложение создаёт рядом со скриптом файл `live_recorder_config.json` — в нём хранятся настройки и список сессий между запусками.

## Использование

### Быстрый старт

1. Запустите `python TwitchBIG.py`.
2. В верхней панели укажите:
   - **Папку** для сохранения файлов;
   - **Сегмент (мин)** — на файлы какой длины резать поток (1–360 минут);
   - **Качество Twitch** — качество для платформы Twitch (`best`, `1080p60`, `720p` и т.д. — для остальных платформ применяется автоматически лучшее доступное через `yt-dlp`).
3. На карточке стримера (создаётся автоматически, можно добавить ещё через "➕ Добавить стримера"):
   - выберите **платформу**;
   - введите **ник канала или полную ссылку** (подсказка под полем ввода меняется в зависимости от платформы и режима);
   - выберите **режим**: "🔴 Поток" (запись эфира вживую) или "📼 VOD" (скачивание архива);
   - нажмите **"▶ Старт"**.
4. Готовые файлы появляются в указанной папке по мере записи — открытый в данный момент сегмент недоступен, но все предыдущие уже полностью готовы к монтажу.
5. Нажмите **"⏹ Стоп"**, чтобы завершить запись — процесс и все его дочерние процессы будут корректно остановлены.
6. **"💾 Сохранить настройки"** сохраняет папку, размер сегмента, качество и список всех текущих сессий — при следующем запуске карточки восстановятся автоматически.

### Режим "🔴 Поток"

Обычная запись идущего эфира. Программа ждёт, пока канал станет онлайн (для Twitch), запускает `streamlink`/`yt-dlp`, пайпит вывод в `ffmpeg -f segment`, и нарезает поток на файлы заданной длины без перекодирования, пока эфир не закончится или вы не нажмёте "Стоп".

### Режим "📼 VOD"

- **Для Twitch**: введите либо просто **ник канала** — тогда программа сама найдёт последний архив (VOD) и определит, идёт ли эфир прямо сейчас, — либо готовую ссылку `twitch.tv/videos/<id>` на конкретный VOD.
  - Если найденный VOD уже завершён — он скачивается целиком обычным способом, с нарезкой на сегменты.
  - Если стрим ещё идёт (VOD растёт) — сначала докачивается уже устоявшаяся часть одним файлом, а затем программа переходит на частый опрос (раз в ~10 секунд) новых данных с последующей склейкой накопленных кусков в файлы нужного размера — так можно начинать монтаж, пока эфир продолжается.
  - После окончания эфира программа не станет качать уже обработанный VOD заново.
- **Для остальных платформ**: нужна прямая ссылка на видео/VOD — автопоиск по одному нику работает только для Twitch.

### Несколько сессий одновременно

Каждая карточка — независимая сессия со своим логом, статусом и кнопками управления. Можно одновременно писать, например, Twitch-эфир одного стримера и YouTube-трансляцию другого — они не мешают друг другу.

## Как это устроено технически

```
streamlink --stdout (Twitch)  или  yt-dlp -o - (остальные платформы)
        │
        │  pipe (без временных файлов на диске)
        ▼
ffmpeg -f segment -segment_time N -c copy  seg_%04d.ts / .mp4
```

- `ffmpeg` в режиме segment-мультиплексора сам режет входящий поток по GOP-границам — без перекодирования и без разрывов закачки.
- Каждый закрытый сегмент сразу пригоден для монтажа — блокируется на запись только текущий, ещё пишущийся файл.
- Отдельный поток (`SegmentWatcher`) следит за папкой вывода и логирует появление готовых файлов.
- При остановке записи убивается всё дерево процессов (`taskkill /F /T` на Windows, `killpg` на POSIX) — так что дочерние `ffmpeg`, порождённые изнутри `yt-dlp`/`streamlink`, не остаются висеть в фоне.

## Известные ограничения

- Автопоиск VOD по одному нику без ссылки работает только для Twitch (использует Twitch GQL API).
- Для остальных платформ в режиме VOD нужна прямая ссылка на видео.
- Работоспособность зависит от актуальности `yt-dlp` и `streamlink` — при изменениях на стороне платформ рекомендуется обновлять их:
  ```bash
  pip install -U yt-dlp streamlink
  ```

## Структура конфигурации

Файл `live_recorder_config.json` создаётся автоматически рядом со скриптом и хранит:
- путь для сохранения файлов;
- длину сегмента в минутах;
- выбранное качество для Twitch;
- список всех сохранённых сессий (платформа, канал/URL, режим записи).

Файл можно удалить, чтобы сбросить настройки к значениям по умолчанию.
