# ⬡ MultiTool

Компактная плавающая панель быстрого запуска для Windows/Linux/macOS на чистом `tkinter`. Держите под рукой ярлыки на часто используемые программы, скрипты и `.exe`-файлы — без загромождения рабочего стола и без штатного лаунчера ОС.

---

## Зачем это нужно

Стандартный способ быстро запустить нужную программу — это либо копаться в меню "Пуск"/доке, либо держать десяток ярлыков на рабочем столе. MultiTool решает это иначе:

- **Одна маленькая всегда доступная панель** с кнопками-ярлыками — добавляете один раз, дальше просто кликаете.
- **Запуск одним кликом**: `.exe`, `.py`, `.lnk` (Windows) и вообще что угодно.
- **Скрипты Python запускаются "из коробки"**: если в `.py`-файле есть импорты пакетов, которых нет в системе, MultiTool сам определит их и предложит поставить через `pip` — не нужно вручную разбираться, что предустановить.
- **Перетаскивание файлов прямо из проводника** — кинули файл на окно, он добавился в панель.
- **Плавный drag-and-drop внутри панели** — можно менять порядок кнопок мышью, с анимацией и "магнитным" позиционированием.
- Все данные (список программ, их порядок, размер и позиция окна) сохраняются между запусками.

---

## Возможности

- ➕ Добавление программ через диалог выбора файла или перетаскиванием (drag'n'drop из проводника/Finder)
- ▶️ Запуск одним кликом: `.exe`, `.py`, `.lnk`, и любые другие исполняемые/ассоциированные файлы
- 📦 **Автоустановка pip-зависимостей** для `.py`-скриптов — MultiTool парсит `import`/`from ... import` через AST, сверяет со стандартной библиотекой и известными несовпадениями имён пакетов (`cv2 → opencv-python`, `PIL → Pillow`, `bs4 → beautifulsoup4` и т.д.) и ставит недостающее одной кнопкой
- 🖱 Перетаскивание кнопок для смены порядка — с плавной анимацией и "прилипанием" к позиции
- 🖊 Переименование ярлыков, просмотр и редактирование информации о файле (путь, размер, дата изменения) через контекстное меню
- 🗑 Удаление ярлыков (кнопкой × на самой кнопке или через контекстное меню)
- 💾 Автосохранение списка программ, их порядка и геометрии окна между запусками
- 🖼 Тёмный интерфейс, подсказки (tooltip) с полным путём при наведении
- ⌨️ Горячая клавиша `Ctrl+O` для быстрого добавления программы

## Требования

- **Python 3.8+**
- Стандартная библиотека `tkinter` (в большинстве дистрибутивов Python идёт по умолчанию; в некоторых Linux-дистрибутивах ставится отдельно, см. ниже)
- Опционально: **`tkinterdnd2`** — без него программа работает нормально, но перетаскивание файлов из проводника/Finder на окно будет недоступно (добавление через диалог "+", кнопку и `Ctrl+O` работает в любом случае)

### Установка

1. Установите Python 3.8 или новее ([python.org](https://www.python.org/downloads/)).

2. Если `tkinter` отсутствует (обычно актуально только для Linux):
   ```bash
   # Debian/Ubuntu
   sudo apt install python3-tk

   # Fedora
   sudo dnf install python3-tkinter

   # Arch
   sudo pacman -S tk
   ```
   На Windows и macOS `tkinter` уже входит в стандартную установку Python.

3. (Рекомендуется) Установите `tkinterdnd2` для поддержки перетаскивания файлов из проводника:
   ```bash
   pip install tkinterdnd2
   ```

4. Скачайте `multitool.py` (или склонируйте репозиторий) и запустите:
   ```bash
   python multitool.py
   ```

> Список программ и настройки окна сохраняются в `~/.multitool_apps.json` (в домашней папке пользователя).

## Использование

### Добавление программы

- Нажмите кнопку **"+"** справа от панели — откроется диалог выбора файла (`.exe`, `.py`, `.lnk` или любой другой).
- Либо перетащите файл(ы) прямо из проводника/Finder на окно программы (если установлен `tkinterdnd2`).
- Либо нажмите `Ctrl+O`.

### Запуск

Просто кликните по кнопке нужной программы.

- `.py`-файлы запускаются тем же интерпретатором Python, которым запущен MultiTool (или системным `python`/`python3`/`py`, если MultiTool собран в `.exe`). Перед запуском MultiTool проверяет импорты в скрипте и, если чего-то не хватает, предлагает установить недостающие пакеты через `pip install` — с прогрессом в отдельном окошке.
- `.exe`/`.lnk` и остальные файлы запускаются штатным способом ОС.

### Управление ярлыками

Кликните правой кнопкой мыши по ярлыку, чтобы открыть контекстное меню:

- **▶ Запустить** — то же самое, что клик левой кнопкой
- **ℹ Информация** — окно с названием, путём, типом, размером и датой изменения файла; название и путь можно отредактировать прямо там
- **✎ Переименовать** — быстрое переименование отображаемого названия (не переименовывает сам файл на диске)
- **✕ Удалить** — убрать ярлык с панели (файл на диске не трогается)

Кнопка **×** на самой кнопке-ярлыке — быстрое удаление без контекстного меню.

### Изменение порядка

Зажмите и потяните любую кнопку — остальные ярлыки плавно "разъедутся", освобождая место. Отпустите в нужной позиции — новый порядок сохраняется автоматически.

### Окно

- Окно можно свободно перемещать и менять его размер — кнопки сами перестраиваются в новую сетку.
- Размер и положение окна запоминаются между запусками.

## Как это устроено технически

- Интерфейс полностью на `tkinter` (без сторонних UI-фреймворков), с ручной анимацией перетаскивания через `after()`-тики и экспоненциальное сглаживание позиций.
- Список программ и геометрия окна хранятся в JSON-файле `~/.multitool_apps.json`.
- Определение недостающих пакетов для `.py`-скриптов делается через разбор AST (`ast.parse`) — импорты сравниваются со списком модулей стандартной библиотеки (`sys.stdlib_module_names`) и таблицей соответствия "имя модуля → имя pip-пакета" для случаев, когда они не совпадают (например, `cv2` → `opencv-python`).
- Поддержка перетаскивания файлов из проводника реализована через опциональную библиотеку `tkinterdnd2`; при её отсутствии эта функция просто отключается, остальной функционал работает без изменений.

---

## Известные ограничения

- Автоопределение и установка pip-зависимостей работает только для `.py`-скриптов и только для импортов, которые получится определить статическим анализом (динамические/условные импорты может не распознать).
- Запуск `.lnk`-ярлыков рассчитан на Windows.
- Перетаскивание файлов из проводника требует установленного `tkinterdnd2` — без него доступно добавление только через диалог выбора файла или `Ctrl+O`.
